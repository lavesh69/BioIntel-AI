BioIntel AI Step 121 (Version 12.1.0)

1. Extract all four Step 121 ZIP parts into the SAME destination folder.
2. Run INSTALL_WINDOWS.bat for the core offline environment.
3. Run VERIFY_STEP121_WINDOWS.bat.
4. Run RUN_APP_WINDOWS.bat.

Step 121 uses the existing core Python dependency set and does not require a new mandatory online package. External provider verification, specialist engines, licensed databases, independent cohorts, wet-lab confirmation and clinical review remain separately supplied and are never marked complete when absent.

BioIntel AI 15.6.0 — Education Suite Integration
================================================

This four-part release preserves the existing BioIntel P0/P1/P2 scientific
runtime, Career Hub and Shiro AI v3, and adds the BioIntel Education Suite.

INSTALLATION
1. Keep all four matching ZIP parts in one folder.
2. Extract all four parts into the same empty destination, preferably C:\BioIntel220.
3. Open BioIntel-Step220.
4. Run START_HERE_WINDOWS.bat, or run INSTALL_WINDOWS.bat followed by RUN_BOTH_WINDOWS.bat.
5. Open BioIntel Classroom and select Education suite.

OPTIONAL INSTITUTIONAL SERVICES
Local lessons, notes, whiteboard, assessments, coding practice, notebook grading,
Q&A, offline library, analytics, resumes and credentials work without a service.
For institution-hosted live classes, multi-user labs, hardened code sandboxes,
LMS bridges and other server features, run:

SETUP_BIOINTEL_EDUCATION_SERVICES_WINDOWS.bat

The setup only records institution-approved endpoints and checks availability.
It does not silently download or install third-party servers.

IMPORTANT
- Do not mix parts from older releases.
- The local code runner is for trusted practice, not hostile or high-stakes code.
- Similarity results are review indicators, not plagiarism findings.
- External opportunities and credentials still require source/evidence review.
- Upstream identities remain in legal/technical notices when legally required.

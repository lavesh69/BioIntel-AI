# Security Policy

## Supported release
BioIntel AI Step 193 / 15.1.0.

## Reporting
Do not include patient data, credentials or proprietary datasets in a vulnerability report. Create a minimal reproducible example, include the Step 191 diagnostics bundle and contact the project owner through the private channel listed in the release record.

## Response states
Received → triaged → reproduced → fixed → regression-tested → released.

## Boundaries
No claim is made that an offline SBOM or static scan replaces an independent penetration test, CVE service or code-signing audit.

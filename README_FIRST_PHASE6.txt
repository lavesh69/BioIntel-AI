BIOINTEL AI 15.6.0 EDUCATION PHASE 6
====================================

1. Put these four files in ONE empty folder:
   BioIntel-AI-15.6.0-EDUCATION-PHASE6-Part1.zip
   BioIntel-AI-15.6.0-EDUCATION-PHASE6-Part2.zip
   BioIntel-AI-15.6.0-EDUCATION-PHASE6-Part3.zip
   BioIntel-AI-15.6.0-EDUCATION-PHASE6-Part4.zip

2. Do not mix Phase 6 ZIPs with Phase 2, 3, 4 or 5 ZIPs.
3. Do not rename the ZIP files.
4. Run EXTRACT_INSTALL_RUN_EDUCATION_4PART_WINDOWS.bat.
5. After installation, run VERIFY_EDUCATION_PHASE6_WINDOWS.bat from the installed source/app folder.
6. Start the optional background worker with RUN_EDUCATION_PHASE6_WORKER_WINDOWS.bat when queued reports, backups or integration operations are required.

External SSO, PostgreSQL, S3/MinIO and LMS qualification requires credentials supplied through environment-variable references. Never paste plaintext production secrets into application forms.

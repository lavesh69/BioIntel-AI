# Local Desktop Guide

Extract all four matching ZIP parts into the same folder or use the supplied four-part extractor. Run `INSTALL_EDUCATION_PHASE23_TO_30_WINDOWS.bat`, then launch BioIntel normally.

User data defaults to `%LOCALAPPDATA%\BioIntelAI\UserData`; override only with `BIOINTEL_USER_DATA_DIR`. Open Education Home first to establish an actor/institution, then use the Education Enterprise and Virtual Science Laboratory pages.

Use the diagnostic, backup and restore batch files before major changes. The worker is optional for queued background jobs. MCP is disabled until explicit credentials are configured.

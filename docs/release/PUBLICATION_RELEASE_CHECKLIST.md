# Publication Release Checklist

1. Run `VERIFY_STEP191_WINDOWS.bat`.
2. Confirm no secrets, patient data or restricted assets are included.
3. Review THIRD_PARTY_NOTICES and SBOM.
4. Select the final licence and update CITATION/CodeMeta.
5. Freeze the four-part package and checksums.
6. Upload to the chosen archive/repository and insert DOI/URLs.
7. Re-run claim-safety validation.
8. Obtain author approval for the manuscript.

# Security Operations Guide

- Assign least-privileged institution roles.
- Separate requesters from approvers for agent, credential and controlled publication workflows.
- Expire and rotate API/MCP credentials; never commit `.env`.
- Require HTTPS for public APIs and webhooks.
- Review audit-chain verification and failed jobs regularly.
- Restrict backup access and test restore.
- Keep external integrations disabled until validated.
- Treat generated educational/research content as a draft until evidence and faculty review are complete.

Automated controls support security operations but do not replace an authorized penetration test, legal/privacy review or accessibility audit.

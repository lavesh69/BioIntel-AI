# Virtual Science Laboratory Handbook

Select an experiment and review objectives, prerequisites, hazards, capability class and protocol version. Start an attempt, acknowledge required safety steps and record values with units.

The service validates state transitions, incompatible units and known unsafe/invalid actions. Notebook entries and attachments persist independently of Streamlit reruns. Submit only when evidence is complete; staff assessment creates a separate record. Exported PDF reports are signed structured evidence, not a physical-lab certificate.

# Administrator Handbook

Administrators create the pilot, accept terms, complete onboarding and approve the go-live transition. Always run imports in dry-run mode, download the error report, verify the confirmation digest and commit only after relationship errors are resolved.

Configure integrations, API keys, webhooks, plugin grants and MCP policies with least privilege. Review health, support tickets, dead-letter jobs, audit-chain verification, storage and backups. Revoke credentials/shares with a reason rather than deleting history.

Do not mark production capacity, accreditation, security certification or institutional acceptance complete without the required external evidence.

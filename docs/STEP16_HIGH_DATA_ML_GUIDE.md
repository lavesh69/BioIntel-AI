# Step 16 High-Data ML Guide

## Data modes

- Quick: 96 rows
- Foundation: 1,920 rows
- Extended: 5,760 rows
- Ultra: 16,000 rows, 400 molecules, 40 targets

## Bundled ML families

Classification: Extra Trees, Random Forest, Logistic Regression, SGD Logistic.

Regression: Extra Trees, Random Forest, Ridge, Elastic Net, SGD Regression.

## Recommended workflow

1. Start in ML AutoLab.
2. Download an input template or choose a bundled pack.
3. Train with drug-group or target-group splitting.
4. Compare validation and untouched test metrics.
5. Use ChEMBL Builder for real experimental data.
6. Treat all bundled-data metrics as software benchmarks only.

# Scientific Module Guide

The platform catalog exposes sequencing quality, alignment/mapping, differential expression, biomarker discovery, variant prioritization, pathway enrichment, multi-omics, single-cell, proteomics, metabolomics, microbiome, structural biology, drug/target discovery, experimental design, statistical analysis, literature discovery, hypothesis generation, and laboratory validation.

Each module documents required canonical columns in the analysis catalog and returns QC, metrics, findings, rankings, warnings, limitations, and provenance. The maturity and optional-dependency status of every module is recorded in the root completion matrix.

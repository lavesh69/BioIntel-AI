# API Guide

The platform FastAPI router is mounted at `/v1/research-platform`. Use `/catalog` for lifecycle, module, workflow, report, and synthetic capabilities. Resource routes cover projects, datasets, samples, workflows, runs, discovery, evidence, hypotheses, recommendations, experiments, validations, reports, models, graph/activity, analytics, operations, dependencies, and synthetic generation.

Use the generated OpenAPI schema for exact request bodies. Typed service errors report remediation and retryability. Configure the parent BioIntel API authentication middleware for deployed use.

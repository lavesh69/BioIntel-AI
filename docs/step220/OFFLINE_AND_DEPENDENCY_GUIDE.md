# Offline and Dependency Guide

Core UI, API, CLI, SDK, SQLite persistence, native analyses, synthetic mode, and report exports are local-first. Optional executables and databases are discovered by the Dependency Manager and never silently emulated.

Install only tools required by your modules, record exact versions/checksums/database releases, and refresh dependency health after configuration. See the root `DEPENDENCY_MATRIX.md` for the verified Windows state and setup boundaries.

# Step220 User Guide

Open **Discovery Lab Platform** from the BioIntel navigation.

## Typical workflow

1. Create or select a project in Portfolio.
2. Record the research question, objective, organism, assays, owners, dates, risks, and milestones.
3. Register datasets and samples in Data and samples, then ingest local scientific files.
4. Review format, schema, duplicate, integrity, origin, and QC states before analysis.
5. Create a workflow template or choose a dataset and production analysis in Analysis.
6. Review run provenance, warnings, limitations, and generated artifacts.
7. Promote defensible findings into candidates, evidence, hypotheses, and recommendations.
8. Plan experiments and record validation outcomes in Evidence and validation.
9. Create a report, review it, and export the required format.
10. Freeze important runs and export reproducibility material before project completion.

## Synthetic mode

Create a synthetic project only for training, demonstration, pipeline verification, or deterministic failure tests. The screen displays the synthetic notice, stores a generator manifest, and runs the fixture through the production analysis engine. Synthetic evidence cannot be assigned to real scientific projects.

## Review rule

A completed run is not a validated scientific conclusion. Check QC, input completeness, evidence independence, contradictory findings, limitations, and external/laboratory validation before acting.

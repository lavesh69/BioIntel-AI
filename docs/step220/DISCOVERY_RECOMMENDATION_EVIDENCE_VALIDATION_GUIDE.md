# Discovery, Recommendation, Evidence, and Validation Guide

Create candidates only from traceable project observations/runs, then rank with declared weights and inspect dossier support, contradiction, QC, risk, limitation, ownership, and action plan fields. Evidence records include source identifiers, versions, study/quality/bias/retraction/correction/verification state, and payload hashes.

Hypotheses require observations and falsification criteria. Recommendations carry component scores and lifecycle state. Experiments define assays, controls, replicates, acceptance/failure criteria, and provenance. Validation outcomes feed back into evidence and confidence but never bypass scientific review.

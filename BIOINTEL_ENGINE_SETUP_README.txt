BIOINTEL SCIENTIFIC ENGINE SETUP
================================

Normal users should run BIOINTEL_ENGINE_SETUP.bat.

The setup menu uses BioIntel component identities and keeps detailed package,
repository, executable and licence diagnostics inside protected technical logs:

  %LOCALAPPDATA%\BioIntelAI\UserData\logs

Required upstream attribution is retained in:

  docs\legal\THIRD_PARTY_NOTICES.md

The legal notices must remain with redistributed builds. Internal executable IDs
and package names are intentionally preserved for runtime compatibility and are
not used as the normal user-facing product identity.

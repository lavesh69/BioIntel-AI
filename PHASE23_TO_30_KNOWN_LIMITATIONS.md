# Phase 23–30 Known Limitations

- No real institution has signed pilot acceptance.
- The 500/1,000/5,000-user profiles are configuration/simulation profiles; production capacity is not verified.
- Live Moodle, Canvas, Classroom, LTI, OneRoster, ORCID, Crossref, PubMed, Europe PMC, SMTP, calendar, S3, OAuth/OIDC and SAML require real credentials and endpoints.
- PostgreSQL, Redis and S3 enterprise runtime paths are reference/configuration profiles, not locally qualified infrastructure.
- External AI provider execution requires provider credentials and governance approval.
- Mastery is transparent rule-based logic, not a validated AI or psychometric model.
- Several Virtual Lab entries are structured guided workflows, not high-fidelity physical simulations.
- No automatic copyright permission, ethics approval, accreditation or employment guarantee is inferred.
- Formal penetration testing, WCAG certification, privacy/legal review and disaster-recovery exercises require qualified external teams.
- Public credential verification URLs need a deployed HTTPS base URL.
- Background adapters intentionally fail to retry/dead-letter when external configuration is absent.
- The broad inherited repository test suite has historical failures; the focused upgrade and target Education/Shiro/Connect regressions are the qualified gates.

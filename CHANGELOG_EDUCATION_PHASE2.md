# Education Universe Phase 2 Changelog

## Added

- Shared Education visual component library.
- Persistent command-center presets and user customisation.
- Role-aware cross-module activity stream and command palette.
- Classroom, Academy and Science Pulse visual-intelligence modes.
- Visual Studio for all twenty Education Universe modules.
- Institution branding, report exports and audited Presentation Mode.
- Phase 2 schema migration and eight focused automated tests.

## Hardened

- Student dashboard, activity, Classroom, Academy and Universe aggregations now reuse actor-level visibility constraints.
- Protected question-bank records cannot be read through visual summaries.
- Logo uploads validate MIME signatures, size and storage containment.
- Scheduled reports stay `configuration_required` until a scheduler is connected.
- Provider and lecture-processing cards do not invent success or time estimates.

## Retained

All Phase 1 pages, operational modes, demo provenance, API behavior, Windows launchers and shared Education database remain in place.

# BioIntel AI 15.6.0 — Education Phase 4

## Education Intelligence Hub
- Added a responsive app workspace for adaptive learning, Shiro Tutor, academic operations, notifications and governed reports.
- Added role-aware navigation and app-style mastery, recommendation, timetable and notification cards.

## Adaptive learning
- Added subject concept graph and prerequisite relationships.
- Added recency-weighted mastery evidence, confidence, practice streak and spaced-review scheduling.
- Added explainable, human-overridable remediation and review recommendations.

## Shiro AI Course Tutor
- Added local indexing of approved subject notes and published learning materials.
- Added citation-grounded English, Hindi and Hinglish tutoring modes.
- Added evidence-status disclosure and no-evidence refusal behavior.
- Added an active-examination lock for student tutor access.

## Academic operations
- Added recurring weekly timetable creation with teacher, room and group conflict detection.
- Added transactional all-or-nothing series creation.
- Added timetable-to-attendance session creation, bulk attendance validation and shortage alerts.

## Notifications and reports
- Added recipient-owned notification inbox, preferences and deduplication.
- Added assignment/examination reminder generation.
- Added governed learner progress reports combining attendance, assignments, results and concept mastery.

## Platform hardening
- Added typed Phase 4 FastAPI contracts.
- Added granular Phase 4 permissions without weakening explicit deny precedence.
- Added import-safe Streamlit compatibility for backend-only verification environments.
- Preserved existing modules and backward-compatible database migration behavior.

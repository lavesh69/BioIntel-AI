Phase 16 extends Phase 15 without removing existing modules or migrations.

- Durable event consumers with acknowledgement cursors, presence heartbeats and retention cleanup.
- Maximum-marginal-relevance evidence retrieval and measurable RAG evaluation using recall@k and mean reciprocal rank.

## Qualification boundaries

Multi-node event fan-out requires a deployed Redis or equivalent broker. External provider credentials, production PostgreSQL/S3 infrastructure, paid Windows signing, independent security/accessibility/load audits and real institutional acceptance remain external evidence requirements.

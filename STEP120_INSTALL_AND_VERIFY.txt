BioIntel AI Step 120 (Version 12.0.0)

1. Extract all four Step 120 ZIP parts into the SAME destination folder.
2. Run INSTALL_WINDOWS.bat for the core offline environment.
3. Run VERIFY_STEP120_WINDOWS.bat.
4. Run RUN_APP_WINDOWS.bat.
5. Optional: run INSTALL_STEP120_SCIENTIFIC_EXTRAS_WINDOWS.bat for online Python extras and the protected specialist-tool installer.

Licensed/proprietary engines and large reference databases must be supplied separately under their own licences. Verification does not mark external validation as passed merely because a tool is installed.

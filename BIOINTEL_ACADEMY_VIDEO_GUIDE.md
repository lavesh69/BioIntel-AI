# BioIntel Academy Video Guide

Accepted UI extensions are MP4, WebM and MOV and the server requires a video MIME type. The original is copied to institution-scoped storage and hashed. If FFmpeg is not installed, the record explicitly shows `processing_dependency_required`; no rendition, thumbnail, transcript or recording is claimed. CDN/object storage, adaptive streaming, resumable multipart upload, malware scanning and speech-to-text require separately configured services and verification.

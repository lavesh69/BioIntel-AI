# BioIntel Education Universe Phase 2

This is a four-part, non-overlapping Windows source release.

1. Put all four `BioIntel-AI-15.6.0-EDUCATION-PHASE2-PartN.zip` files in one empty folder.
2. Extract every ZIP into that same folder. Do not concatenate the ZIPs.
3. Confirm one merged `BioIntel-Step220` directory exists.
4. Run `INSTALL_WINDOWS.bat`, then `RUN_BOTH_WINDOWS.bat`.
5. Open Classroom, Science Pulse, Academy or Education Universe. Use **Load full demo workspace** for the isolated synthetic scenario.

Run `VERIFY_EDUCATION_PHASE2_WINDOWS.bat` for the Education regression suite.

External AI, media processing, conferencing and report scheduling remain configuration-dependent. Presentation Mode always displays the synthetic-data warning.

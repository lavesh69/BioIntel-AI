# Trusted local model artifacts

Only model files generated by this BioIntel AI project should be stored here.

Serialized Python objects can execute code during loading. BioIntel does not
accept arbitrary uploaded Joblib or pickle files and verifies that selected
paths remain inside this trusted directory.

## Artifact format

Current compatible artifact format: `7.0.0`

Artifacts include:

- experiment ID
- dataset SHA-256
- train/validation/test row counts
- held-out metrics and confidence intervals
- feature schema and exact feature order
- training configuration
- software versions
- applicability statistics
- JSON metadata sidecar
- Markdown model card

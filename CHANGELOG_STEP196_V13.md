# BioIntel AI Step 196 · V13 four-part UI Upgrade

Version 15.3.0 · Windows-first local release · four ZIP parts.

## What V13 improves

- Delivers the full Windows release in five complementary ZIP files, reducing each download to roughly 165–170 MB.
- Updates the installer, runner, repair path, runtime preflight and source validation to require all four matching parts.
- Replaces cramped five-to-eight-column status strips on selected high-traffic screens with responsive metric boards.
- Rebuilds Quick Start into grouped, descriptive launch cards for intelligence, scientific workflows, governance, data/ML and workspace support.
- Gives the formerly flat Step 189, Step 190 and Step 193 command centers the shared premium visual hierarchy: hero, boundary, status cards, tabs and readable tables.

## What V13 does not change

- It does not increase a scientific, technical, validation, governance or controlled-release rating.
- It does not manufacture evidence, qualification, approval, external confirmation, licensed rights, wet-lab results or regulatory clearance.
- The required Windows flow remains: extract all four matching parts, then run `INSTALL_WINDOWS.bat`, then `RUN_BOTH_WINDOWS.bat`.

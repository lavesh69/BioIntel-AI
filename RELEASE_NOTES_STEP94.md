# BioIntel AI 9.4.0 — Step 94 Pro Upgrade

## Upgraded workbenches
- Pangenome: GFA1/GFA2 parsing, topology audit, components, bubble candidates, path comparison.
- Long-read: FASTQ.GZ QC, Q20 yield, N90, coverage estimate, auN/L50, command plans and tool preflight.
- Protein design: BLOSUM62-aware mutation ranking, Pareto front, uncertainty, PDB C-alpha context and property deltas.
- CRISPR/Perturb-seq: replicate-aware guide analysis, BH-FDR, guide consistency, UMAP/PCA and differential markers.
- Outbreak genomics: uploaded metadata/distance matrices, SNP-time-space link scores and minimum-spanning forests.
- Synthetic biology: synthesis QC, restriction/homopolymer/repeat scans, Gibson primer planning, codon optimization and GenBank export.
- Rare disease: multi-sample VCF parsing, computational evidence fields, transparent ACMG-assistance prompts and CNV/SV review.
- Knowledge graph: importable node/edge tables, multi-hop paths, conflict detection, citation coverage and research gaps.
- Biomarkers: nested cross-validation, in-fold imputation/selection, bootstrap CIs, calibration, permutation testing and external validation.
- Workflow builder: editable dependency DAG, cycle validation, resumable internal execution and persistent run history.
- Advanced tools: module-readiness matrix and reproducibility lock export.

## Scientific boundary
This release improves engineering, analysis depth and reproducibility. It does not manufacture independent clinical, regulatory, wet-lab or publication evidence. Those ratings can only improve through real external validation.

# Step 191 Internal Reproducibility Benchmark Protocol

1. Use deterministic module-specific fixtures generated by the frozen release.
2. Execute each of 80 modules three times with unchanged inputs and parameters.
3. Record input/output SHA-256, runtime and classification metrics.
4. Pass when output hashes match, F1 ≥ 0.75 and expected calibration error ≤ 0.15.
5. Label the benchmark as internal and synthetic; do not describe it as independent external validation.
6. For a scientific performance paper, add independently sourced truth sets and established-tool comparators under compatible licences.

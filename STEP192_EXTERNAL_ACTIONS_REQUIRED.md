# Step 192 External Actions Required

These items cannot be completed honestly inside an offline build:

1. Choose an owner-approved journal-compatible software licence if the target journal requires open-source licensing.
2. Publish a public repository and archive a frozen release to obtain a DOI.
3. Approve the final manuscript and author/contributor list.
4. Run independent external comparisons on genuine datasets and qualified hardware.
5. Supply real wet-lab, clinical, scanner, instrument or multi-site evidence where a module's intended claim requires it.
6. Obtain expert, legal, ethics, security and regulatory approvals applicable to the intended use.

The application must continue to report these items as pending until authentic evidence is attached.

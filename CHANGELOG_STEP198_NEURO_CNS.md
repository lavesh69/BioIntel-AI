# Step198 — Neuro/CNS Scientific Hardening & Feature Expansion

## Implemented

- Hardened all 23 Neuro/CNS engines with stronger validation, explicit applicability boundaries and expanded outputs.
- Added unit-normalized concentration/affinity schemas and multi-dose oral/IV brain-exposure simulation.
- Added Hill-aware receptor occupancy, selectivity margins and invalid-row isolation.
- Added mutation-delta aggregation analysis, enhanced off-target context and coverage-aware side-effect reporting.
- Added richer VCF-like parsing, variant QC, structural-variant recognition and research-only prioritization evidence.
- Added batch-aware omics ranking with FDR, bootstrap effect intervals and internal cross-validation.
- Added neural-signal filtering, artifact QC, spectral entropy, connectivity, coherence and candidate-event tables.
- Added adapter-aware EDF/BDF/FIF, NIfTI and DICOM loading with strict fail-closed behavior when optional dependencies are absent.
- Added Otsu/percentile segmentation, connected-component metrics, confound regression and partial connectivity.
- Added cluster-count assessment, bootstrap stability, subgroup/outcome summaries and quality warnings for precision neurology.
- Added guided disease, compound-to-clinic and target-to-translation workflows.
- Added cross-module consistency rules, resource provenance registry and controlled-release status.
- Added persistent local projects, portable project import/export and JSON/HTML/Markdown unified reports.
- Added persistent Neuro/CNS background jobs for heavy batch, omics, EEG, imaging, trial, variant and cohort workloads.
- Added expanded automated qualification covering all 23 modules and Step198 hardening features.

## Scientific boundary

Step198 improves software functionality, transparency, reproducibility and workflow depth. It does not manufacture external validation. Bundled target, expression and side-effect content remains demo/reference material. Clinical diagnosis, treatment recommendation, medical-device use and controlled scientific release remain ineligible until approved data bindings, independent benchmarks, expert review and responsible sign-off are complete.

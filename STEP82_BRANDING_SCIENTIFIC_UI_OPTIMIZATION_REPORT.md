## Themes

Fifteen additional complete scientific experience themes were added, bringing the total to 32. Each new theme has a dedicated dark palette, light palette, chart profile, layout archetype, geometry, navigation treatment, hero surface, controls and scientific use case.

New themes: Genomic Noir, Helix Quantum, CRISPR Cyan, Proteome Platinum, Cell Atlas, Neural Biotech, Quantum Enzyme, Botanical Circuit, Clinical Sapphire, Molecular Carbon, Spatial Omics, BioLuminescence, Pathway Gold, Cryo-EM Frost and Synthetic Biology.

## Performance

- Smooth-performance mode enabled for the packaged default profile
- Fixed backgrounds replaced with scroll-attached surfaces
- Expensive blur/elevation can be disabled while preserving theme geometry
- CSS generators use bounded in-process caching
- Plotly template rebuild is skipped until relevant appearance inputs change
- Desktop stylesheet reads are cached by file signature
- Active-page detection avoids `inspect.stack()` on the normal execution path
- Database-health cache increased from 45 to 300 seconds
- Paint containment added to cards, metrics, plots and dataframes

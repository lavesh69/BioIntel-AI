# Step 12 — Experience Shortcomings Fixed

## Tool discovery

With many screens, finding the correct module required scanning the sidebar.
Command Center now supports search, categories, favourites and recent tools.

## Preference persistence

Step 11 appearance preferences lasted only for the current session. Step 12
stores non-sensitive preferences locally and restores them after restart.

## Workflow onboarding

New users lacked a single readiness checklist. Command Center now shows
diagnostics, dataset, model, default-model and experiment progress.

## Evidence reporting

Workspace information was spread across dashboards and registries. Report
Studio creates one polished printable HTML and JSON evidence snapshot.

## Repeated navigation

Global Quick Dock now provides consistent shortcuts, favourites and recent
tools on every page.

## Accessibility polish

Focus-visible outlines, progress styling and persistent reduced-motion/high-
contrast preferences improve repeat use.

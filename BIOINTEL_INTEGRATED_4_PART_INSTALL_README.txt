BIOINTEL AI - P0 + P1 + P2 SCIENTIFIC INTEGRATION RUNTIME V2
================================================================

INSTALL THE FOUR-PART RELEASE
-----------------------------
1. Keep all four new ZIP files in one folder.
2. Do not mix them with any older BioIntel ZIP parts.
3. Extract all four ZIP files into the same destination.
4. Recommended destination: C:\BioIntel220
5. Open the merged BioIntel-Step220 folder.
6. Run START_HERE_WINDOWS.bat or INSTALL_WINDOWS.bat.
7. After installation, run RUN_BOTH_WINDOWS.bat.

SCIENTIFIC INTEGRATION SETUP
----------------------------
Run BIOINTEL_ENGINE_SETUP.bat and select:
  1 = P0 core scientific integrations
  2 = P1 advanced scientific integrations
  3 = P2 model and pipeline integrations
  4 = P0 + P1 + P2 together
  5 = Verify installed integrations

Heavy dependencies are installed into isolated BioIntel runtimes under the
current Windows user profile. Missing optional components do not block the
core BioIntel app.

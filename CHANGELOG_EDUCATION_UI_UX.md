# Education UI/UX Changelog

## 15.6.0 Education Universe Upgrade — 2026-07-28

### Added

- Role-aware Education Command Center.
- Native twenty-module categorized Education Universe hub.
- Search, category/availability/collection filters, favourites, recent modules and recommendations.
- Schema-guided persistent forms, records, review transitions, audits and readiness panels.
- Shared Education data-path resolver for UI and API.
- Native Streamlit dark BioIntel theme tokens.
- Isolated deterministic demo engine with two institutions, fourteen personas and four scenarios.
- Demo manifest, metadata sidecar, safe reset, CLI scripts and quoted Windows launchers.
- Eight demo/isolation regression tests and upgrade qualification reports.

### Changed

- Classroom, Science Pulse, Academy and Education Universe pages now share permanent demo controls and truthful workspace labelling.
- Education FastAPI and Streamlit defaults now resolve through the same data-root policy.
- Education Universe raw JSON-first interaction is replaced by guided native forms; advanced stored payloads remain reviewable.

### Preserved

- Existing Classroom, Academy, Science Pulse, Shiro AI and BioIntel Connect features.
- Tenant/role isolation, student question-bank denial, safety guards, audit transitions, optimistic locking and explicit offline conflict resolution.

### Known boundaries

- Shiro/lecture/provider outputs remain configuration-dependent and do not report success without a real output.
- The twenty specialist Universe domains use professional guided workspaces; not every domain is a separate bespoke vertical application in this fifty-credit release.
- Synthetic research/news records are educational demonstration metadata, not live sources.

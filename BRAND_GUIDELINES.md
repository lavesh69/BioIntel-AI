# BioIntel AI Brand Guidelines

## Brand lockup

**BioIntel AI**  
Scientific Intelligence for Life Sciences  
**Biology, Engineered into Intelligence.**

BioIntel AI is an evidence-aware scientific intelligence platform for biological research, data analysis and reproducible discovery.

## Brand personality

Precise, intelligent, evidence-aware, modern, calm, premium, scientific and trustworthy.

## Product architecture

| Family | Purpose |
|---|---|
| BioIntel Genomics | Sequence, genome, variant and pathogen intelligence. |
| BioIntel Discovery | Target, compound, structure and developability workflows. |
| BioIntel Lab | Assay, instrument, wet-lab and process analytics. |
| BioIntel Omics | Transcriptomic, proteomic, single-cell and multi-omics analysis. |
| BioIntel Models | Training, evaluation, validation and lifecycle governance. |
| BioIntel Evidence | Provenance, evidence review, release gates and reporting. |
| BioIntel Operations | Projects, workflows, reliability, storage and deployment. |

## Logo policy

- Use the full-colour mark on dark or neutral surfaces.
- Use the white or dark monochrome mark when contrast requires it.
- Keep clear space equal to at least one quarter of the mark width.
- Do not add glow, stretch, rotate or recolour the logo.
- Animation is reserved for launch only and must finish within 1.5 seconds.

## Typography

- Interface: Inter with Segoe UI and Arial fallbacks.
- Data/code: IBM Plex Mono, JetBrains Mono or Consolas.
- Use no more than two font families in one product surface.
- All caps are reserved for short metadata labels.

## Motion

- Page and control transitions: 180-260 ms.
- Hover elevation: maximum 2 px.
- Chart reveals: 300-500 ms when motion is enabled.
- No continuous decorative movement, bouncing icons or animated chart backgrounds.
- Always honour reduced-motion preferences.

## Scientific trust language

Every result should communicate evidence level, confidence, dataset state, model state and provenance. Required status vocabulary:

- Demo
- Reference data
- Experimentally validated
- External validation pending
- Research use only
- Release eligible

Never present synthetic or reference-only assets as clinical, regulatory or experimentally validated evidence.

## Module naming rules

- Analyzer: one focused analysis.
- Workbench: multi-step specialist analysis.
- Studio: interactive design or creation.
- Lab: experimental or model-development environment.
- Hub: aggregated resources.
- Command Center: cross-module orchestration.
- Registry: provenance and records.
- Review Board: human scientific review.

## Home and shell hierarchy

Primary shell: logo, search, workspace context, notifications and settings. Version and founder attribution belong in About, Credits, documentation and report metadata rather than every header.

## Data visual language

Control = blue; treatment = cyan; positive = green; warning = amber; critical = red; uncertainty = grey; reference = violet. Every chart should include title, interpretation, units, method, sample count, data export and evidence status when available.

## Report identity

Reports use the BioIntel lockup, project/module name, input checksum, analysis settings, evidence status, generation time, version and research-use notice. Footer: `Generated with BioIntel AI - Evidence-aware scientific intelligence`.

## External launch assets

Store and website imagery must follow one narrative: unified workspace, data import, analysis and visualisation, AI-assisted discovery, evidence/provenance and reproducible reporting.

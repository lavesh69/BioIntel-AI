# Phase 15 Four-Part Reconstruction

Keep all four ZIPs in one empty folder and run `EXTRACT_INSTALL_RUN_EDUCATION_PHASE15_4PART_WINDOWS.bat`.

The archives contain non-overlapping source paths under `BioIntel-Step220/`. Each archive includes an embedded part manifest and Phase 15 marker. The installer reconstructs the source into a short LocalAppData path before calling the deep-verified Windows installer.

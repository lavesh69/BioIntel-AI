# Step 11 — Visual and UX Shortcomings Fixed

## Inconsistent screen styling

Earlier screens used default Streamlit surfaces and page-specific layouts.
Step 11 introduces one reusable visual system applied across the application.

## Weak hierarchy

Large workflows could feel like long forms. Step 11 adds hero sections,
section dividers, glass cards, premium metrics and consistent spacing.

## Generic charts

Plotly charts previously depended on default styling. Step 11 adds a global
transparent dark template, aurora colorway, softer grids and styled hover labels.

## Navigation density

The sidebar now has a clear BioIntel brand block, active-page treatment,
rounded navigation rows and stronger hover feedback.

## Accessibility

Users can enable:

- Reduced motion
- Higher contrast
- Compact spacing

## Personalisation

Appearance Studio offers four session-based accent palettes without requiring
an account or storing personal preferences remotely.

## Responsive design

Page padding, hero sizes and card layouts adapt better on smaller screens.

# Real Scientific Data Import Checklist

This directory intentionally contains no fabricated experimental data. Before importing a real source:

1. Record the official release/version and retrieval date.
2. Review licence, redistribution and attribution terms.
3. Preserve the original file checksum.
4. Curate units, assay relations, compound structures and target identifiers.
5. Register rejected rows and reasons.
6. Run leakage, duplicate and conflict audits.
7. Require reviewer sign-off before scientific release.

Use `IMPORT_REAL_EVIDENCE_WINDOWS.bat` for supported activity tables.

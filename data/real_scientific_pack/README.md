# BioIntel AI Verified Real Scientific Data Pack

This local pack contains **10 checksum-bound public/reference dataset groups** from official or established scientific providers.

Included coverage: reviewed protein sequences, an experimental macromolecular structure, curated pathway hierarchy, a real biomedical ML benchmark, verified ChEMBL activities, official ClinVar references, a ClinicalTrials.gov reference snapshot, multi-organism identifiers, an official-provider catalog, and a compact genuine GEO expression excerpt.

## Boundary

These assets support format testing, software validation, method development, education and reproducibility. They do **not** make every model clinically validated, regulatory approved, prospectively validated or fit for patient-care decisions. Provider licences, citations and original study context must be retained.

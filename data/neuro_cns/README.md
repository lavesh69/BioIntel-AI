# Neuro/CNS bundled resources

This folder contains local demo/reference resources and software capability manifests for the 23-engine Neuro/CNS Studio.

- `target_registry_v1.json` and `side_effect_map_v1.json` are demonstration/reference snapshots, not controlled-release scientific datasets.
- `step199_feature_registry.json` describes the nine advanced scientific laboratories.
- `step200_max_potential_feature_registry.json` describes the nine validation, reliability and release-control systems added in Step200.
- `resource_registry_v2.json` is regenerated during release verification and records checksums, installation state and scientific qualification gates.

No bundled resource is a substitute for licensed provider data, independent validation, clinical review or regulatory approval.

## Step201 completion layer

Step201 adds a local scientific-resource binding registry, specialist-engine inventory, privacy/de-identification guardrails, analytic study-design planning, cohort-leakage auditing, dataset-drift monitoring, multi-site reproducibility analysis, professional PDF reporting and an integrity-preserving release evidence pack. These systems improve software completeness and scientific reviewability; they do not manufacture licences, external validation, clinical evidence or controlled-release approval.

## Step202 production-readiness and synthetic demo layer

Step202 adds ten production-readiness systems, robust CPython 3.11.x Windows detection, extraction/path/disk/wheelhouse/demo preflight, a one-click 23-module synthetic demonstration runner, update snapshots, role-access controls, review records, compute qualification, privacy-redacted diagnostics, benchmark gates and publication/release export packs. The bundled Step202 demo data contain no real patient records and are never controlled-release eligible.

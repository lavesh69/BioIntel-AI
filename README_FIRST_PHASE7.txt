BIOINTEL AI 15.6.0 EDUCATION PHASE 7 DESKTOP
==============================================

1. Put these four files in ONE empty folder:
   BioIntel-AI-15.6.0-EDUCATION-PHASE7-Part1.zip
   BioIntel-AI-15.6.0-EDUCATION-PHASE7-Part2.zip
   BioIntel-AI-15.6.0-EDUCATION-PHASE7-Part3.zip
   BioIntel-AI-15.6.0-EDUCATION-PHASE7-Part4.zip

2. Do not mix Phase 7 ZIPs with Phase 2, 3, 4, 5 or 6 ZIPs.
3. Do not rename the ZIP files.
4. Run EXTRACT_INSTALL_RUN_EDUCATION_4PART_WINDOWS.bat.
5. After installation, run VERIFY_EDUCATION_PHASE7_WINDOWS.bat from the installed source/app folder.
6. Start the optional worker with RUN_EDUCATION_PHASE7_WORKER_WINDOWS.bat for queued reports, backups or integration jobs.

The new main desktop page is:
  BioIntel Education Desktop

Mobile-specific redesign and qualification are intentionally outside Phase 7 scope.
External SSO, PostgreSQL, S3/MinIO and LMS qualification still requires real credentials supplied through environment-variable secret references. Never paste plaintext production secrets into application forms.

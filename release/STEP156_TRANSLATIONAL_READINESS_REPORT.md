## Qualification upgrades

Executable presence alone is no longer treated as readiness. A qualified specialist-engine record requires executable/version evidence, checksummed reference assets, pinned releases, licence evidence, reviewer identity and review timestamp. Laboratory imports retain raw SHA-256 and are blocked when instrument identity, calibration, method/SOP version, operator or one-to-one schema mapping is incomplete.

## Runtime hardening

API and job components no longer require write access inside the packaged application folder. Jobs, API security, tenant records, feature cache, run registry and logs use a writable runtime directory while preserving the immutable installed package.

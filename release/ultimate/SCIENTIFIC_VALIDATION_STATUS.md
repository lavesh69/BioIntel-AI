# Scientific Validation Status

BioIntel AI 15.6.0 Step206 is a research software platform. Its software gates test imports, schemas, deterministic fixtures, error boundaries, module pages and selected computational contracts. These tests do not establish clinical validity, regulatory approval, pharmaceutical validation or biological truth.

The generated module registry labels functionality and external requirements per module. Scientific-depth profiles record required engines, references, validation checks, optimization strategies and explicit claim boundaries. Demo/synthetic outputs remain labelled. External engines/databases are reported as external until exact assets and qualification evidence are present.

Existing independent/public benchmark evidence is preserved with dataset/model provenance where available. Any module without independent representative evidence remains **Not validated** for that use, even when its software workflow is functional.

Required downstream validation depends on the question and can include locked protocols, leakage-resistant splits, calibration, subgroup analysis, external cohorts, replicates, negative/positive controls, orthogonal assays, expert review, uncertainty analysis and exact engine/database/model versioning.

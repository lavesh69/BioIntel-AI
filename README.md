## Supported Windows workflow

After extracting all five matching Step206 ZIP parts into one new folder, use only:

1. `INSTALL_WINDOWS.bat`
2. `RUN_BOTH_WINDOWS.bat`

The installer verifies all four parts, the active SHA-256 source manifest, the bundled offline wheelhouse, compatible CPython 3.11.x x64, managed LocalAppData installation, database backup/migration, and a native Windows UI/API/worker startup-and-shutdown smoke test. It refreshes stable Desktop and Start Menu shortcuts so the installed app no longer depends on the extracted download folder.

`RUN_BOTH_WINDOWS.bat` uses a resident supervisor with strict API, Streamlit, local SQLite read/write and worker readiness checks. Startup failure cleans all owned processes and creates sanitized diagnostics. Ollama, SearXNG and external providers remain optional and isolated from the offline core.

See `CURRENT_RELEASE.md`, `CHANGELOG_STEP206_WINDOWS_INSTALL_RUN.md` and `RELEASE_TEST_REPORT_STEP206.md`. Step205 scientific upgrade records remain available for provenance.

Historical provenance includes Step 159 runtime-resilience foundations and later release gates; Step206 is the active release.

V19.6 retains the complete V19.1–V19.5 scientific, collaboration and engine-platform work. The ultimate professional hardening adds canonical repair/diagnose/safe-mode/uninstall controls, a central 269-entry product registry, reproducible module/engine/model/reference exports, sanitized diagnostics, UserData-preserving recovery and a stricter four-part release gate. Run `INSTALL_WINDOWS.bat` from the newly extracted V19.6 package before `RUN_BOTH_WINDOWS.bat`.

After installation, `RUN_ULTIMATE_ACCEPTANCE_WINDOWS.bat` performs the final target-machine software qualification and writes its evidence under the dedicated UserData reports directory.

Step216 is not clinical authorization, regulatory validation, wet-lab
validation, model-weight qualification or external-engine qualification.

target-machine evidence passes.

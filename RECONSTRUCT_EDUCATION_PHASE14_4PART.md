# Reconstruct BioIntel Education Phase 14

Place all four matching `BioIntel-AI-15.6.0-EDUCATION-PHASE14-PartN.zip` files in one empty folder and run `EXTRACT_INSTALL_RUN_EDUCATION_PHASE14_4PART_WINDOWS.bat`.

Manual extraction is also supported: extract all four ZIPs into the same destination. The union must create one `BioIntel-Step220` directory. Do not mix parts from prior phases.

After reconstruction:

1. Run `INSTALL_WINDOWS.bat` from `BioIntel-Step220`.
2. Run `VERIFY_EDUCATION_PHASE14_WINDOWS.bat`.
3. Start queued operations with `RUN_EDUCATION_PHASE14_WORKER_WINDOWS.bat`.

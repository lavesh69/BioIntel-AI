BIOINTEL AI 15.6.0 — CAREER HUB BIOINTEL THEME FINAL
=====================================================

This four-part release contains the complete prior P0/P1/P2 integrated build plus
the BioIntel-themed Career, Internship & Scholarship Hub upgrade.

IMPORTANT
---------
1. Download all four files from this exact release.
2. Do not mix these files with any older Part1/Part2/Part3/Part4 ZIPs.
3. Place all four ZIP files in one folder.
4. Extract all four ZIPs into the same destination, recommended:

   C:\BioIntel220

5. The merged application folder must be:

   C:\BioIntel220\BioIntel-Step220

6. Start with:

   START_HERE_WINDOWS.bat

   Or run in order:

   INSTALL_WINDOWS.bat
   RUN_BOTH_WINDOWS.bat

CAREER HUB LOCATION
-------------------
The hub appears directly in the BioIntel sidebar and under the Education domain:

Career, Internship & Scholarship Hub

The old page route remains compatible and opens the same canonical BioIntel UI.

DATA NOTICE
-----------
Opportunity information can change. Confirm deadlines, funding, eligibility and
application instructions at the official source before applying. Demo and newly
submitted records are not presented as automatically verified.
